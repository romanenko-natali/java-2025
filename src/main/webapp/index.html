🎓 Student Management API

RESTful API for managing students, teachers, groups, subjects, and courses.

🧪 Test

GET /api/test - Check if application is running

📚 Students

GET /api/students - Get all students
GET /api/students/{id} - Get student by ID
POST /api/students - Create new student
PUT /api/students/{id} - Update student
DELETE /api/students/{id} - Delete student

👨‍🏫 Teachers

GET /api/teachers - Get all teachers
GET /api/teachers?department=X - Filter by department (partial match)
GET /api/teachers/{email} - Get teacher by email
POST /api/teachers - Create new teacher
PUT /api/teachers/{email} - Update teacher
DELETE /api/teachers/{email} - Delete teacher

👥 Groups

GET /api/groups - Get all groups
GET /api/groups?specialty=X - Filter by specialty (partial match)
GET /api/groups?number=X - Filter by group number
GET /api/groups?active=true - Get active groups only
GET /api/groups?graduated=true - Get graduated groups only
GET /api/groups/{fullName} - Get group by full name (e.g., CS01-23)
POST /api/groups - Create new group
PUT /api/groups/{fullName} - Update group
DELETE /api/groups/{fullName} - Delete group

📖 Subjects

GET /api/subjects - Get all subjects
GET /api/subjects?minCredits=X&maxCredits=Y - Filter by credits range
GET /api/subjects/{name} - Get subject by name
POST /api/subjects - Create new subject
PUT /api/subjects/{name} - Update subject
DELETE /api/subjects/{name} - Delete subject

🎯 Courses

GET /api/courses - Get all courses
GET /api/courses?subject=X - Filter by subject name
GET /api/courses?teacher=X - Filter by teacher name (partial match)
GET /api/courses?group=X - Filter by group name (partial match)
GET /api/courses/{identity} - Get course by identity
POST /api/courses - Create new course
PUT /api/courses/{identity} - Update course
DELETE /api/courses/{identity} - Delete course

Built with Java Servlets, Jackson, SLF4J/Logback
